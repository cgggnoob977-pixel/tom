# FixFlow — ระบบวิเคราะห์งานซ่อม

แดชบอร์ดภาษาไทยสำหรับติดตามงานแจ้งซ่อมอุปกรณ์ วิเคราะห์งานค้าง อาการเสีย ค่าใช้จ่าย และคุณภาพข้อมูล ใช้ CSV ที่ผู้ใช้ส่งมาเป็นแหล่งข้อมูลจริง ไม่ใช้ข้อมูลจำลองหรือส่งข้อมูลออกไปยังบริการภายนอก

## เริ่มใช้งาน

1. เปิด `index.html` ด้วยเว็บเบราว์เซอร์ หรือเปิดโฟลเดอร์นี้ผ่านเว็บเซิร์ฟเวอร์แบบ static
2. เว็บไซต์ทำงานแบบออฟไลน์ได้และไม่ต้องติดตั้ง dependencies
3. ไฟล์ `data/computer_repair_dirty_200.csv` เป็น CSV ต้นฉบับ ส่วน `data.js` เป็นสำเนาข้อมูลสำหรับให้หน้าเว็บทำงานได้โดยตรงแม้เปิดจาก `file://`

ถ้าใช้ Python และต้องการเปิดผ่าน local server:

```powershell
python -m http.server 8000
```

จากนั้นเปิด `http://localhost:8000`

## หน้าหลัก

- **ภาพรวม** — จำนวนงาน สถานะ คะแนนพึงพอใจ แนวโน้มรายเดือน และอาการที่พบบ่อย
- **รายการซ่อม** — ค้นหา กรอง เรียงลำดับ แบ่งหน้า และส่งออก CSV ตามตัวกรอง
- **งานที่ต้องติดตาม** — งานที่ยังไม่ซ่อมเสร็จ แสดงระดับเร่งด่วนและวันที่แจ้ง
- **วิเคราะห์เชิงลึก** — สถิติเวลาซ่อม การกระจายค่า และข้อสังเกตเพื่อวางแผน
- **คุณภาพข้อมูล** — แสดงปัญหา วิธีจัดการ และ Data dictionary

ตัวกรองวันที่ สถานะ ความเร่งด่วน แผนก และคำค้นใช้ร่วมกันทุกหน้า ปุ่ม “ล้างตัวกรอง” คืนค่าการแสดงผลเป็นข้อมูลทั้งหมด

## ขอบเขตการคำนวณและคุณภาพข้อมูล

- ไฟล์ต้นฉบับมี 200 แถว และมีรายการซ้ำที่เหมือนกันทุกฟิลด์ 1 แถว (รหัส R164) เว็บไซต์คงรายการแรกไว้และไม่นับรายการซ้ำ
- ตัดช่องว่างหัวท้ายข้อความก่อนใช้วิเคราะห์ แต่ไม่แก้หรือเติมค่าว่างด้วยการคาดเดา
- วันที่ที่ไม่มีอยู่จริงยังแสดงในรายการงาน แต่ไม่รวมในแนวโน้มรายเดือน และไม่ผ่านตัวกรองวันที่
- เวลาซ่อมที่ติดลบไม่รวมในสถิติเวลา; ค่าอะไหล่ที่ติดลบไม่รวมเฉพาะยอดค่าอะไหล่; คะแนนพึงพอใจนอกช่วง 1–5 ไม่รวมในค่าเฉลี่ย
- ค่าสูงสุดของเวลาซ่อม (60 ชั่วโมง, R182) ถูกแสดงให้ตรวจสอบแต่ยังคงอยู่ในสถิติ เพราะไม่มีหลักฐานหรือ SLA ที่ยืนยันว่าค่านี้ผิด
- ค่าว่างของงานที่ยังไม่ปิดถือเป็นข้อมูลที่ยังไม่เกิดขึ้นและไม่ถูกเติม
- ไม่มีวันปิดงานหรือ SLA ในชุดข้อมูล จึงไม่คำนวณอายุงานค้างหรือสรุปว่างานเกินกำหนด
- ยอดค่าใช้จ่ายรวมเฉพาะค่าที่เป็นตัวเลขตั้งแต่ 0 ขึ้นไปของงานที่ซ่อมเสร็จ ไม่ได้แทนค่าว่างด้วยศูนย์
- ตัวกรองวันที่เมื่อกำหนดช่วง จะไม่รวมแถวที่มีวันที่ผิดรูปแบบ; จำนวนงานปกตินับรายการไม่ซ้ำโดยไม่ต้องมีวันที่ถูกต้อง
- สถิติเวลาซ่อมแสดงค่าเฉลี่ย มัธยฐาน ส่วนเบี่ยงเบนมาตรฐานแบบประชากร ค่าต่ำสุด และค่าสูงสุด

## ตรวจสอบการใช้งาน

1. เปิดแต่ละรายการใน Sidebar และตรวจว่าหน้าปัจจุบันเปลี่ยนตามหัวข้อ
2. กรองสถานะ/แผนก/ช่วงวันที่ร่วมกัน แล้วตรวจว่าตัวเลขและรายการเปลี่ยนตาม
3. กดล้างตัวกรองเพื่อตรวจว่ากลับมาแสดงข้อมูลทั้งหมด
4. ค้นหารหัส `R001` และส่งออก CSV เพื่อตรวจว่าข้อมูลในไฟล์ตรงกับรายการที่แสดง
5. ตรวจหน้า “คุณภาพข้อมูล” สำหรับรายการซ้ำและค่าผิดปกติ พร้อมดูหมายเหตุเรื่องตัวหารของแต่ละตัวชี้วัด

เว็บไซต์นี้เป็นแดชบอร์ดแบบ static สำหรับชุดข้อมูลตัวอย่างจากผู้ใช้ ไม่ใช่ระบบจัดเก็บหรืออัปเดตสถานะงานซ่อมแบบ real-time
